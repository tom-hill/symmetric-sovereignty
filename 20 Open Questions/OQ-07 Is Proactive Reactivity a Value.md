## Wider implication
If the notebook set is "seven values + one principle + one thesis", then Part 2 should say what *kind* of thing a value is — which is what Tom is really asking. A working definition from the material: **a value is a tension held by the self; a principle is a way of holding it; a duty is a tension owed to another.**

## Naming history (recovered 2026-09-16)

The transcripts show the value set began as the **"Hill Credo"** and was written in a heavily personal vocabulary that has since been stripped out — the "S.E.E. Armory", the "Shield" and the "Heart", the "Loonshot" and the "Franchise", "debt mountains", "messy labs". Tom's own instruction for the rewrite was that the descriptions were "rooted in my notes, not in the representations of those values in tension", and asked for each to stand on **the principle of the tension itself** rather than the scaffolding of personal notes.

That rewrite is why the current definitions read as they do. It also means the set has already survived one deliberate generalisation pass — which is relevant here, because if Proactive Reactivity survived a pass explicitly designed to strip personal scaffolding and still doesn't read as a value, that is evidence it is something else rather than evidence it is badly worded.

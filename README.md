# Symmetric Sovereignty

A philosophy of life, the individual, the professional, and business — written in the open while it is still being worked out.

> Health — in a person, an organisation, an economy, a nation — is found not in resolving opposing forces but in consciously holding them.

This is not a finished book, and it is not intended to become one quickly. It is a working repository: the argument as it currently stands, the questions it cannot yet answer, and the questions that are still only a sense that something is missing. It is published while in progress, deliberately, so that it can be argued with before another year is built on top of it.

## The core, in one screen

- **Tension** is the generative condition, not a problem to solve.
- **Values** take the form *X without Y* — a strength held against what it becomes when it stops holding. Self-administered; they cannot be prescribed.
- **Duties** are owed to a counterparty who can invoke them, which is why they scale where values do not.
- **Kindness** is the mechanism that stops values inverting into their shadows.
- **Normalisation** is the adversary — but possibly not in the way first argued. See [OQ-14](20%20Open%20Questions).
- **Symmetric** names an *act*, not a state: holding power such that no party is overwhelmed and none can foreclose another.

## On the machine

Parts of this repository were written in dialogue with Claude, an AI assistant. Every contribution it made is marked — either inside a `> [!claude]` callout or in the `Claude/` folder — and none of it is merged silently into the author's text. That convention exists because the framework's first value is sovereignty over one's own thinking, and a philosophy that used a machine to write itself without saying so would have failed its own test on page one. The open question about whether that is sufficient is [OQ-04](20%20Open%20Questions), and it is not closed.

## What is not here

The handwritten notebooks, the dialogue transcripts, the professional practice, and correspondence with others. The notebook in particular is where the thinking is actually done and where being wrong in private is the point. This repository holds the worked-up material, not the workings.

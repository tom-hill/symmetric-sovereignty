# UQ-04 — Does the vault shape the philosophy?

## The sense
The philosophy now lives in a structure: twelve numbered folders, a note type per kind of thought, a template per note type, a graph. That structure was designed by a machine in an afternoon.

Structure is not neutral. A filing system that has a folder for *concepts* will generate concepts. A template with a "## The shadow" heading will find shadows. A graph view rewards ideas that link and quietly buries ideas that do not.

## What it sits next to
[[Authorship vs Imposition]] — a norm authored elsewhere and imposed is the framework's own definition of the harmful case, and this is a norm authored elsewhere · [[OQ-04 The Herbert Question]] · [[Normalisation]] · [[Process Philosophy]] — a process cannot be understood by stopping it, and a vault is a way of stopping it

## The version that would be worth asking
Not "is the vault biasing me" — everything biases everything. The sharper one: **what kind of thought does this structure make hard?** Something that is neither a concept, a value, a duty, a question nor an influence has nowhere to go, so it does not get written down, so it does not exist. What has already been lost that way?

The notebook does not have this problem. That may be the actual argument for keeping it primary.

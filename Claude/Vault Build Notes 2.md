# Vault Build Notes

Decisions made while converting the Claude project into this vault, for the record.

- **Folder numbering** puts orientation first, the work second, support last. The graph view is meant to be the primary navigation; folders are for humans who prefer them.
- **One note per value** rather than one note for all values, because each will grow independently and each needs its own backlinks from concepts and questions.
- **Open questions never deleted.** A resolved OQ is part of the argument's history.
- **Claude's voice** is confined to `> [!claude]` callouts and the `Claude/` folder. This is a deliberate answer to [[OQ-04 The Herbert Question]] in miniature, and it lets Tom prune every one of my contributions with a search for `[!claude]`.
- **`> [!blank]`** marks deliberate gaps. Obsidian renders unknown callout types with a default style; a CSS snippet can make them distinctive.
- **Transcriptions are literal**, including Tom's spelling ("it's own"), strikethroughs, and "Buy blotting paper!". The notebook is the primary source; tidying it would be a small normalisation.
- **Assets renamed** for legibility; bytes untouched; originals' names recorded in [[Assets README]].
- **Cross-project material** (Reyor positioning, income target, H+G heuristics) included where it bears on the philosophy's application — this vault is about the philosophy *and* its test-bed.
- **Not included:** dialogue transcripts (unavailable), the second `photo.jpeg` (unretrievable), the reading list's contents (not recorded), the private journal (deliberately separate). → [[Provenance]]
- **Dates:** `created: 2026-09-15` on every note is the vault date; the underlying thinking is older.

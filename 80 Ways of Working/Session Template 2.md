# Session Template

*How to run a philosophical session so its output lands in the vault cleanly. Copy [[Session Log Template]] into `70 Threads` and fill it.*

## Before
1. Pick **one** open question from [[Open Questions Index]].
2. Read its note and the concepts it links to.
3. Write the opening structured question(s) in the notebook first, by hand.

## During
- Work the one question deeply. Resist the second question.
- Name the mechanism. Name smuggled resolution words.
- When a principle recurs from a new direction, note it — it counts toward [[Convergence as Evidence]].

## After
1. Create the session note in `70 Threads` from [[Session Log Template]].
2. Update the open question: `status`, and **Resolution** if resolved — with a link to where the answer was written.
3. Write the answer into the Book part or Concept it belongs to. Mark Claude's contributions.
4. If a new question emerged, create `OQ-nn` from [[Open Question Template]] and add it to the index.
5. Update [[Status and Next]].
6. Photograph any new notebook spread → `90 Assets` → [[Notebook Spread Template]].

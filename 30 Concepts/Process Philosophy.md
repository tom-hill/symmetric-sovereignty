# Process Philosophy

## Definition (as held)
Understanding moves *with* a process rather than stopping it. Via [[Frank Herbert]] ("a process cannot be understood by stopping it") and, in the reading list, [[Heraclitus]] and [[Bergson]].

## Where it does work in the framework
- [[Tension]] can't be resolved because resolving is stopping
- [[Commitment without Rigidity]] quotes it directly
- [[Inductive Method]] — the book is built session by session
- The vault is a *baseline*, not a finish → [[Part 10 — Process and the Machine]]
